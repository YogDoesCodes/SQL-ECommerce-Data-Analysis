🛒 **E-Commerce Data Analysis Using SQL**
📌 Project Overview

This project is an end-to-end E-Commerce Data Analysis system built using MySQL.
It simulates a real-world online retail business and demonstrates practical SQL skills including:

Database design

Data cleaning

Data exploration

Business problem solving

KPI generation

Analytical querying

The goal of this project is to apply SQL in a business context — moving beyond basic queries into structured data analysis.

🎯 **Business Objective**

To analyze transactional e-commerce data and generate meaningful insights that help answer key business questions such as:

How much revenue is being generated?

Which products and categories perform best?

Who are the most valuable customers?

How does monthly performance trend?

And much more....



What is customer retention behavior?

This project replicates the type of analysis performed by Data Analysts and Business Intelligence professionals in industry.
